# Chupapo Api

This repository contains the source code for the REST API created to power the [Chupapo website](https://chupapo.com/).

## Features

- Role-based access
- Session-based authentication
- CSRF protection
- Argon2 password hashing

## Built With

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Maven
- Docker and Docker Compose
